# Node handle

参考文档

* [Node handle](https://en.cppreference.com/w/cpp/container/node_handle)

关联容器(Associative containers)都是基于节点的，每个节点就存储了用户插入的数据，节点可以从容器中提取出来，作为一个对象使用。

节点句柄是一个只能移动的类型(move-only),它拥有并提供接口访问它所存储的数据。如果节点句柄在拥有数据时被析构，那么它会正确地使用容器的`allocator`.节点句柄包含容器`allocator`的副本。

标准并未指定节点句柄的确切类型，但是每个容器都有成员类定义`node_type`表示节点句柄的类型。

节点句柄通常是用来在两个具有相同关键字，值与分配器的关联容器中传递对象的所有权，它不会调用存储元素的移动或者是复制构造函数。换句话说，相当于把一个节点从一个容器剪去，移植到另一个容器中去。把节点句柄从独一无二关键字的容器传递到允许相同关键字的容器是允许的，比如可以把`std::map`中的节点传递到`std::multimap`,但却不能传递到`std::unordered_map`或`std::set`

当然，节点句柄也可以是空的，不包含任何的元素与分配器，空的节点句柄可以用来表示从容器提取元素的失败结果。

指向节点句柄中元素的指针与引用在这个元素被传递给节点句柄时仍然有效，但是会在节点句柄成功插入到另一个容器后失效。

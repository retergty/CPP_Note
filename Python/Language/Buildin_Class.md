# 内置类型

## List

列表是Python中最常用的数据结构之一，用于存储有序的元素集合。列表使用方括号`[]`表示，元素之间用逗号分隔。

```python
# 创建一个列表
my_list = [1, 2, 3, 4, 5]
print(my_list)  # 输出: [1, 2, 3, 4, 5]
``` 

## tuple

元组是Python中的另一种内置数据结构，用于存储有序的元素集合。与列表不同，元组是不可变的，一旦创建就不能修改。元组使用圆括号`()`表示，元素之间用逗号分隔。

```python
# 创建一个元组
my_tuple = (1, 2, 3, 4, 5)
print(my_tuple)  # 输出: (1, 2, 3, 4, 5)
```

### 元组解包

元组解包是指将元组中的元素分别赋值给多个变量。可以通过在等号左侧列出变量名来实现。

```python
# 元组解包
my_tuple = (1, 2, 3)
a, b, c = my_tuple
print(a)  # 输出: 1
print(b)  # 输出: 2
print(c)  # 输出: 3
```

多余的可以使用`*`来接收

```python
# 元组解包，使用 * 接收多余的元素
my_tuple = (1, 2, 3, 4, 5)
a, b, *rest = my_tuple
print(a)     # 输出: 1
print(b)     # 输出: 2 
print(rest)  # 输出: [3, 4, 5]
```

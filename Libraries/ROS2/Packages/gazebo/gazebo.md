# gazebo

`gazebo`是一个物理仿真开源工具，可以方便地进行物理仿真。

## 概念

### 实体Entity

实体指的就是`gazebo`里的一个`model`.定义了`joint`,`link`等组件。

### 组件Components

组件指的就是`gazebo`里的实体所具有的属性，比如`joint`,`link`等.

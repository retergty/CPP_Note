# ARM Neon

`NEON`是`ARM`的`SIMD`向量计算技术。

## 架构

### 寄存器

`AArch64`有`32`个`SIMD`/浮点寄存器

```text
V0, V1, V2, ... V31
```

每个寄存器宽度固定为`128 bit`,可以被解释为不同的数据格式，比如

例如同一个`V0`可以被看成：

* `V0.16B`: `16`个`8-bit`元素
* `V0.8H`: `8`个`16-bit`元素
* `V0.4S`: `4`个`32-bit`元素
* `V0.2D`: `2`个`64-bit`元素

### lane

每个寄存器里面的元素就叫做`lane`,是`SIMD`并行计算的基本单位

`SIMD`对每个`lane`独立计算,`lane`之间不会相互影响。

假设:

```text
a = [1, 2, 3, 4]
b = [10, 20, 30, 40]
```

执行

```CPP
float32x4_t c = vaddq_f32(a, b);
```

则是每个`lane`独立相加

```CPP
lane 0: 1 + 10 = 11
lane 1: 2 + 20 = 22
lane 2: 3 + 30 = 33
lane 3: 4 + 40 = 44

c = [11, 22, 33, 44]
```
